# Media Capture Guide (Images, Video, GIF)

This is the step-by-step capture workflow for your first Medium article.

## 1) Screenshot Capture

Use existing screenshots first from:

- `docs/media/screenshots/`

If you need new shots:

1. Open app in one clean browser profile (no personal tabs/bookmarks).
2. Keep a stable viewport width (desktop recommended).
3. Keep browser zoom constant.
4. Capture in this sequence:
   - repo import/indexing
   - chat with citations
   - learning role selection
   - full learning track
   - challenge/quiz screen
   - dependency graph overview
   - dependency graph drill-down
5. Export as PNG (preferred) or JPEG.
6. File naming: `NN_DescriptiveName.png` for ordered storytelling.

## 2) Demo Video (60-90s)

Goal: show the full product loop quickly.

Flow script:

1. Start on repo import.
2. Show indexing completion.
3. Ask one architecture question in chat.
4. Open one learning track and one challenge.
5. Open dependency graph.
6. End on CTA slide or repo link.

Practical tips:

- Record at 1080p.
- Keep cursor movement intentional and slow.
- Remove dead time (loading waits) in edit.
- Add captions/subtitles for accessibility.
- Export and upload to YouTube or Loom, then embed URL in Medium.

## 3) Optional GIF

Use only when one short loop explains a micro-interaction better than a screenshot.

- Keep under 8 seconds.
- Keep dimensions moderate.
- Use once, not repeatedly.
- Prefer video embed if file size gets large.

## 4) Security and Privacy During Capture

- Never show `.env` files.
- Never show API keys or tokens.
- Never show private internal URLs or credentials.
- Blur or remove any personal account identifiers.
