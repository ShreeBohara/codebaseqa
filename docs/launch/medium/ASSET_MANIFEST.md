## Capture Workflow (For New/Replaced Shots)

1. Use a consistent browser width for all captures.
2. Hide bookmarks/tabs/profile data.
3. Keep zoom level fixed across captures.
4. Avoid exposing `.env`, API keys, tokens, or private repo names.
5. Export as PNG/JPEG only for Medium compatibility.
