## Quality Gate Questions

- Could a new developer understand the product after the first two sections?
- Could a reader choose correctly between hosted and local setup?
- Were any comments asking for clarification on unclear claims?
- Did users report broken links or missing assets?

## Decision Rules (Post +7d)

- If read ratio is low: tighten hook + cut long paragraphs.
- If clicks are low: strengthen CTA and move links earlier.
- If stars are low but clicks high: improve GitHub landing README and quick-start.
- If comments focus on one feature: prioritize part 2 article around that feature.
